产品、AI、工程、行业四个方向互相咬合：能定义问题，也能把方案做到可以被验证的程度。

HOW I WORK

我的工作方式。

先结论、后过程；先成果、后职责。用案例证明能力，而不是用形容词。

01 / UNDERSTAND 把问题问清楚

先区分「现象」与「原因」，明确谁在承受成本、什么指标在恶化。

02 / DEFINE 缩到最小可用

定义 MVP 边界与验收标准，先解决一个真实痛点，再谈扩展。

03 / BUILD 用原型说话

用 Prompt / Agent 工作流与 Vibe Coding 把方案做成能点开的东西。

04 / VALIDATE 让数据回流

把使用结果变成下一版的输入，形成可持续迭代的闭环。
